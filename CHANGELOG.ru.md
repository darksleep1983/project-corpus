# История изменений

## 0.1.0 — private preview

- Один единый репозиторий с протоколом, template, сервером, скриптами установки,
  инструкциями клиентов, тестами и примерами.
- Поддержка Streamable HTTP и stdio.
- Понятный быстрый старт на русском и английском.
- Защита записи через SHA, проверенные backups, атомарную публикацию, readback и
  audit receipts.
- Русский и английский шаблоны Corpus с выбором языка при установке.
- Обратная связь через GitHub Issues и добровольная поддержка проекта через
  USDT в сети TON на обоих языках.
