# Code of Conduct

[Русская версия](CODE_OF_CONDUCT.ru.md)

Be respectful, specific, and constructive.

- Discuss ideas and implementations, not personal characteristics.
- Do not publish secrets, private project data, credentials, or identifying logs.
- Report security issues privately as described in `SECURITY.md`.
- Maintainers may remove abusive, unsafe, irrelevant, or deceptive content.
