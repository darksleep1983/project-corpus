# Вклад в проект

[English](CONTRIBUTING.md)

Делайте изменения небольшими, проверяемыми и совместимыми со всеми тремя
режимами доступа.

Перед Pull Request:

1. запустите `python -m unittest discover -s tests -v`, если доступен Python
   3.11+;
2. не добавляйте secrets, machine-specific paths, пользовательские данные Corpus
   или backups;
3. обновляйте русскую и английскую пользовательскую документацию вместе;
4. сохраняйте согласованность семи authority-файлов и правил защиты;
5. объясняйте изменения режимов доступа, синхронизации и границ безопасности;
6. не добавляйте встроенный сервер или обязательный пользовательский runtime без
   отдельного архитектурного решения.

Python используется только для тестов репозитория; пользователям Project Corpus
он не нужен.
