# Вклад в проект

Делайте изменения небольшими, проверяемыми и совместимыми с границей безопасности.

Перед Pull Request:

1. запустите python -m unittest discover -s tests -v;
2. не добавляйте секреты, machine-specific paths, созданные данные Corpus, backups
   или audit logs;
3. обновите русскую и английскую пользовательскую документацию, если меняется
   поведение;
4. объясните любое изменение allowlist записи, проверки путей, backup-логики или
   модели подключения клиентов.
