# Шаблон инструкции проекта

Используйте эту общую инструкцию в любом режиме:

```text
Этот AI-проект использует Project Corpus — набор из семи авторитетных
Markdown-файлов для одного активного проекта.

В начале новой сессии получи семь точных current-файлов через выбранный режим
доступа. Сначала полностью прочитай AGENTS.md, затем выполни его порядок загрузки
и правила. Не подменяй Corpus памятью чата или файлами другого проекта. Отделяй
сохранённые утверждения от свежих live-доказательств.

До сильных решений выдай квитанцию загрузки и краткий смысловой отчёт: полученные
файлы, полнота чтения, роли, связи, опорный центр, пробелы и готовность.

В обычной работе никогда не переписывай AGENTS.md и OPERATOR_PROFILE.md. Обновляй
только фактически изменившиеся mutable current-файлы и нужные Task/Report.
```

Затем добавьте один блок выбранного режима.

## Прямая папка

```text
Режим: DIRECT_FOLDER.
Используй только явно разрешённую filesystem-границу Corpus/проекта. Подтверди
точную папку и реальные права чтения/записи. До записи заново прочитай current-
файл и сохрани backup или version-control checkpoint. Перечитай изменённые файлы
и сообщи before/after hashes, если они доступны.
```

## Свой MCP

```text
Режим: OWNER_MCP.
Используй только настроенные доверенные MCP-tools этого Corpus. Проверь точный
root и доступные возможности настоящими tools сервера. Не предполагай
универсальную health-команду и не заявляй о backups, атомарной записи, hashes или
receipts, если сервер их реально не предоставляет и не проверяет.
```

## Ручная сессия

```text
Режим: MANUAL_SESSION.
Считай загруженные файлы снимками. Подтверди наличие всех семи канонических
current-файлов и отсутствие неоднозначных дублей имён. При синхронизации верни
только current-файлы с реально изменившимся содержанием плюс новые или
изменённые Task/Report, список изменений, старые/новые SHA-256, если их можно
вычислить, и точный следующий шаг. Не заявляй, что что-либо сохранено на моём
компьютере.
```
