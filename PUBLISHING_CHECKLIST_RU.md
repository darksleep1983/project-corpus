# Проверка перед публикацией

[English](PUBLISHING_CHECKLIST.md)

1. Создать репозиторий `project-corpus` со статусом **Private**.
2. Загрузить содержимое этой папки в корень репозитория.
3. Убедиться, что `.project-corpus.local.json`, `.venv`, `.env`, Corpus пользователя и MCP backups не попали в Git.
4. Проверить GitHub Actions.
5. Просмотреть всю историю коммитов на локальные пути, имена пользователей и секреты.
6. Проверить README на чистом компьютере или в новой виртуальной машине.
7. Создать draft release `v0.1.0-preview`.
8. Только после проверки изменить visibility на Public.
