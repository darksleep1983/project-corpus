# Project Corpus

[English](README.md)

[Языковая политика](docs/languages.ru.md)

> Постоянная локальная память для долгого проекта с AI.

Project Corpus хранит самое важное о проекте в нескольких понятных Markdown-файлах: цель, текущее состояние, решения, задачи, отчёты и следующий шаг. MCP-сервер позволяет совместимому AI-клиенту читать эти файлы и безопасно обновлять их по строгим правилам.

Разбираться во внутреннем устройстве MCP для обычного использования не нужно.

## Зачем это нужно

Чат заканчивается. Контекст теряется. В новой сессии или другой модели снова приходится объяснять:

- что это за проект;
- что уже решили;
- какая задача сейчас активна;
- что действительно проверено;
- что AI разрешено менять;
- что делать дальше.

Project Corpus сохраняет это не внутри чата, а локально на вашем компьютере.

## Как это выглядит

```text
Установить Project Corpus
→ выбрать папку
→ подключить свой AI-клиент
→ описать проект обычными словами
→ продолжать его в новых чатах без восстановления контекста с нуля
```

## Что лежит внутри

```text
project-corpus/
├── template/          Чистая заготовка памяти проекта
├── src/               MCP-сервер
├── scripts/           Установка, запуск и проверка
├── docs/              Простые инструкции
├── examples/          Небольшой обезличенный пример
└── tests/             Проверки установки и правил записи
```

После установки создаётся Corpus:

```text
AGENTS.md
OPERATOR_PROFILE.md
PROJECT_ROADMAP_CURRENT.md
MCP_CONNECTION_CURRENT.md
LOADER_PROMPT_CURRENT.md
SESSION_HANDOFF_CURRENT.md
SESSION_HANDOFF_FULL_CURRENT.md
Tasks/
Report/
```

## Быстрый старт за пять минут

### Windows

Нужен Python 3.11 или новее.

Откройте PowerShell в папке репозитория:

```powershell
.\install.ps1 -ProjectHome "D:\AI\MyProject" -Language ru
.\start.ps1
```

### macOS или Linux

```bash
./install.sh "$HOME/AI/MyProject" --language ru
./start.sh
```

Установщик создаст:

```text
<ProjectHome>/Corpus
<ProjectHome>/mcp-state
```

Выберите `en` или `ru` при установке. Установщик создаст Corpus на выбранном
языке и локальный конфигурационный файл в папке репозитория. Пароли и API-ключи
для самого Project Corpus не нужны.

## Что защищает сервер

Сервер имеет доступ только к одной выбранной папке Corpus. Он обеспечивает:

- полное чтение файлов и SHA-256;
- разделение создания и обновления;
- защиту от устаревшей записи через `expected_sha256`;
- резервную копию перед обновлением;
- атомарную замену файла;
- проверку записанного содержимого;
- audit receipt;
- защиту постоянных файлов протокола;
- отсутствие произвольного доступа к остальной файловой системе.

Простое объяснение находится в разделе [Как это работает](docs/how-it-works.ru.md).

## Важные ограничения

- Это проектная память и контролируемый файловый процесс, а не универсальный агент управления компьютером.
- Сохранённый отчёт не доказывает, что служба или программа прямо сейчас работает.
- Не храните в Corpus пароли, токены, cookies и API-ключи.
- Не открывайте локальный HTTP-сервер в интернет напрямую. Для удалённого доступа нужен доверенный защищённый tunnel или gateway.
- Подключайте только те MCP-серверы, коду и разрешениям которых доверяете.

## Текущий статус
