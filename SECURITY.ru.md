# Политика безопасности

[English](SECURITY.md)

Не создавайте публичную Issue для уязвимости, которая может привести к
неавторизованному доступу к файлам, разрушительной синхронизации, обходу границ
инструкций, раскрытию секретов или небезопасной настройке клиента/MCP.

Используйте GitHub Private Vulnerability Reporting на вкладке **Security**
репозитория, когда эта функция доступна. Если она недоступна, свяжитесь с
владельцем через приватный способ, указанный в его GitHub-профиле. Не публикуйте
чувствительные подробности в Issue.

Никогда не прикладывайте реальные tokens, cookies, credentials, private keys,
seed-фразы, приватные файлы Corpus или идентифицирующие локальные пути.

Репозиторий не содержит исполняемого сервера. Уязвимости стороннего MCP-сервера
нужно сообщать его разработчику, если проблема не вызвана документацией Project
Corpus.
