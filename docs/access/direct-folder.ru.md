# Режим прямой папки

[English](direct-folder.md)

Используйте `DIRECT_FOLDER`, если AI-клиент умеет читать локальные файлы и, с
вашего разрешения, записывать их внутри выбранного workspace.

## Настройка

1. Скопируйте `template/ru` или `template/en` в безопасную папку `Corpus`.
2. Поместите Corpus внутрь workspace проекта либо явно разрешите клиенту доступ
   только к этой папке.
3. В `CORPUS_ACCESS_CURRENT.md` запишите:
   - `Mode: DIRECT_FOLDER`;
   - точный путь к папке;
   - разрешена ли запись;
   - способ backup;
   - время последней реальной проверки доступа.
4. Дайте клиенту соответствующий project instruction template.

Не открывайте целый домашний диск только ради одной папки Corpus.

## Начало сессии

Попросите AI:

1. полностью прочитать `AGENTS.md`;
2. прочитать остальные шесть current-файлов;
3. показать `Tasks/` и `Report/`;
4. загрузить только нужные scoped-файлы;
5. выдать квитанцию загрузки и смысловой отчёт.

## Завершение сессии

Попросите синхронизировать Corpus. AI должен:

- заново прочитать current-файлы до изменения;
- сохранить backup или использовать version control;
- менять только фактически затронутые mutable current-файлы;
- не менять `AGENTS.md` и `OPERATOR_PROFILE.md` в обычной работе;
- перечитать изменённые файлы и сообщить before/after hashes, если они доступны.

Протокол направляет AI, но реальную техническую границу задают права файловой
системы и sandbox клиента.
