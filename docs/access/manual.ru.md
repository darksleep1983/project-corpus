# Режим ручной сессии V1

[English](manual.md)

Используйте `MANUAL_SESSION` с любым AI-чатом, если не хотите настраивать доступ
к локальной папке или MCP.

Эта инструкция относится к исходному шаблону V1. Для нового Corpus V2 следуйте
[Quick Start для V2](../quickstart.md).

## В начале новой сессии

Загрузите семь current-файлов:

```text
AGENTS.md
OPERATOR_PROFILE.md
PROJECT_ROADMAP_CURRENT.md
CORPUS_ACCESS_CURRENT.md
LOADER_PROMPT_CURRENT.md
SESSION_HANDOFF_CURRENT.md
SESSION_HANDOFF_FULL_CURRENT.md
```

Затем добавьте только относящиеся к запросу Tasks и Reports. Вставьте секцию
ручного режима из `PROJECT_INSTRUCTION_TEMPLATE.ru.md`.

Попросите AI сначала прочитать `AGENTS.md`, полностью прочитать каждый переданный
authority-файл и выдать квитанцию загрузки до основной работы.

Избегайте неоднозначных дублей. Если платформа сохраняет два загруженных файла с
одинаковым каноническим именем, удалите старый или явно укажите текущую версию.

## В конце сессии

Используйте запрос:

> Синхронизируй Project Corpus для ручного режима. Не переписывай AGENTS.md и
> OPERATOR_PROFILE.md. Верни только current-файлы, содержание которых реально
> изменилось, плюс новые или изменённые Task/Report. Добавь список изменений,
> старые и новые SHA-256, если их можно вычислить, и точный следующий шаг. Не
> заявляй, что файлы сохранены на моём компьютере.

После этого:

1. сделайте backup каждого локального файла, который будете заменять;
2. проверьте канонические имена возвращённых файлов;
3. замените только перечисленные файлы;
4. заново откройте их и проверьте ожидаемое содержание;
5. оставьте только одну current-версию каждого канонического имени.

## Чего ручной режим не доказывает

AI видит загруженные снимки, а не live-файлы на вашем компьютере. Без отдельной
свежей инструментальной проверки он не может доказать, что вы сохранили замену,
что процесс запущен или что внешняя система исправна.
