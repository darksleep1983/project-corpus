# Использование Project Corpus с другим AI-клиентом

[English](other-clients.md)

Выберите самый узкий режим, который поддерживает клиент:

1. `DIRECT_FOLDER`, если он умеет работать с явно разрешённой локальной папкой;
2. `OWNER_MCP`, если у вас уже есть доверенный файловый MCP-сервер;
3. `MANUAL_SESSION`, если клиент принимает только приложенные или вставленные
   файлы.

Клиент должен полностью читать все семь current-файлов. Для автоматической
синхронизации он также должен уметь записывать или возвращать файлы-замены.
Записывайте в `CORPUS_ACCESS_CURRENT.md` только реально проверенные возможности.

Если у клиента есть собственный файл постоянных инструкций, оставьте его коротким
и направьте на `AGENTS.md`. Не поддерживайте две независимые копии протокола.

Не считайте, что слова «filesystem access» или «MCP support» автоматически
означают безопасное ограничение путей, backups, атомарную запись или readback.
