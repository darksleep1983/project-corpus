# Contributing

Project Corpus values small, reviewable changes that preserve the distinction
between Protocol and Runtime.

Before opening a pull request:

1. Run `python -m unittest discover -s tests -v` with Python 3.11+.
2. Keep English and Russian user documentation synchronized where applicable.
3. Do not add secrets, private paths, generated user Corpus data, or backups.
4. Explain any effect on authority, access modes, compatibility, or guarantees.
5. Do not introduce a required Runtime, bundled server, or architectural change
   without an explicit decision.

Read the full [contributing guide](https://github.com/darksleep1983/project-corpus/blob/main/CONTRIBUTING.md),
[code of conduct](https://github.com/darksleep1983/project-corpus/blob/main/CODE_OF_CONDUCT.md),
and [security policy](https://github.com/darksleep1983/project-corpus/blob/main/SECURITY.md).
