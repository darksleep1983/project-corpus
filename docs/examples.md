# Examples

The V2 examples are complete, small project trees rather than fragments. Each
includes `AGENTS.md`, canonical V2 state documents, portable policy, a Task,
and a Report.

- [Software project](https://github.com/darksleep1983/project-corpus/tree/main/examples/software-project)
  demonstrates a bounded feature task, test evidence, and a next engineering
  action.
- [Research project](https://github.com/darksleep1983/project-corpus/tree/main/examples/research-project)
  separates verified findings from claims still requiring verification.
- [Content project](https://github.com/darksleep1983/project-corpus/tree/main/examples/content-project)
  tracks an approved draft task and publication evidence without treating a
  planned publication as completed.
