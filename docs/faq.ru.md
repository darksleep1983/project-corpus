# Частые вопросы

[English](faq.md)

## Это просто ещё один memory bank?

Нет. Memory bank помогает агенту помнить информацию. Project Corpus также
определяет каноническую идентичность, текущее операционное состояние,
доказательства, точное следующее действие и границы полномочий.

## Нужен ли MCP?

Нет. Используйте прямую локальную папку или ручную загрузку файлов. MCP
необязателен.

## Является ли Project Corpus системой Living Software Organism?

Нет. Project Corpus — самостоятельно полезный Protocol состояния проекта и
необязательный Runtime. Living Software Organism — архитектура более высокого
уровня и reference direction, который может использовать Project Corpus как
основу. Project Corpus не требует LSO.

## Что такое Context Intelligence?

Необязательная функция Runtime 2.2.0: строит одноразовый индекс по Markdown в
разрешённом scope, ищет контекст с учётом полномочий и времени и собирает
ограниченные Context Bundles для любого ИИ-агента.

## Является ли Context Bundle авторитетным источником?

Нет. Это неавторитетный указатель на нужные источники. Перед утверждением о
полномочиях или текущем состоянии прочитайте канонические Markdown-файлы.

## Нужны ли LLM, векторная или внешняя база данных?

Нет. Локальный индекс можно пересобрать; LLM, векторная или внешняя база
данных и сеть не требуются.

## Нужен ли Python или installer?

Для Markdown Protocol — нет. Скопируйте V2-шаблон и начните работать вручную.
Python 3.11+ нужен только необязательному локальному Runtime.

## Можно ли использовать его с ChatGPT, Codex или Claude?

Да. Любой клиент, читающий Markdown, может работать вручную. Клиенты с
локальными файловыми tools могут использовать прямую папку.

## Может ли Runtime получить доступ ко всему диску?

Не только из содержимого проекта. В controlled Runtime операции ограничены его
hard limits, внешним owner trust grant с привязкой к одному physical root,
project policy и client capability subset. В direct-folder режиме всё ещё
действуют разрешения, выданные AI-клиенту.

## Это sandbox?

Нет. Markdown Protocol не является sandbox безопасности. Необязательный Runtime
даёт ограниченные гарантии только в документированных controlled-режимах на
проверенных локальных filesystem. Он не делает безопасным сторонний AI-клиент
или MCP host.

## Работает ли это на сетевых дисках?

Не следует этого предполагать. Network, FUSE, removable и другие
неквалифицированные filesystem находятся за пределами измеренных гарантий
Runtime; controlled mutation fail closed, если filesystem не квалифицирована.

## Могут ли несколько агентов редактировать одновременно?

Используйте одного авторитетного writer за раз. Runtime имеет локальный writer
control в поддерживаемом single-project режиме; distributed locking и
multi-project coordination в нём нет.

## Зачем нужны `PROJECT.md` и `STATUS.md`?

Стабильная идентичность и операционное состояние изменяются с разной частотой.
Раздельные canonical documents делают полномочия яснее и уменьшают ненужные
конфликты.

## Почему не database?

Markdown остаётся проверяемым, переносимым, независимым от поставщика и
доступным без установки. Другая система может использовать database, но она не
нужна для этого Protocol.

## Отправит ли он весь проект в интернет?

Сам Project Corpus ничего не отправляет. Облачный AI получает то, что вы
загрузили или что для него прочитал подключённый tool. Проверьте data policy
клиента и передавайте только необходимое.

## Можно вести два проекта в одном Corpus?

Нет. Для каждого активного проекта используйте отдельный Corpus.

## Можно переименовать файлы?

В V2 заданы канонические пути и имена файлов; сохраняйте их, чтобы инструменты
и клиенты находили обязательные записи. Существующие проекты V1 сохраняют
исходные имена. Следуйте инструкции по миграции, чтобы создать отдельное
назначение V2.

## Зачем Tasks и Reports?

Task определяет, что разрешено и требуется. Report фиксирует, что действительно
сделано и проверено. Разделение не позволяет принять план за доказательство.

## Ручной режим обновит мои локальные файлы?

Нет. AI вернёт файлы-замены, а backup и сохранение выполняете вы.

## Можно ли мигрировать V1?

Да. Runtime предоставляет read-only планирование миграции и отдельную
controlled create-only публикацию V2. Шаблоны V1 остаются неизменными; перед
authorizing apply прочитайте migration guide.

## Доступен ли PyPI?

Да. Необязательный Runtime можно установить из PyPI командой `pip install project-corpus`.
