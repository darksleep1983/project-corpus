# Частые вопросы

## Это только для ChatGPT или Claude?

Нет. Сервер использует MCP. Любой совместимый клиент может подключиться, если
поддерживает выбранный transport и нужные разрешения.

## Он отправит весь мой проект в интернет?

Нет. Сервер читает только настроенную папку Corpus. AI-клиент получает содержание
файлов, когда сам вызывает инструмент; это регулируется политикой обработки данных
вашего клиента. Проверьте её до подключения.

## Он управляет всем компьютером?

Нет. Встроенный сервер читает и записывает только Corpus по своей политике.

## Можно вести два проекта в одном Corpus?

Протокол намеренно допускает один активный проект на один Corpus. Для отдельного
проекта создайте другой Corpus и отдельную конфигурацию сервера.

## Можно переименовать файлы?

Да, но тогда нужно согласованно изменить и протокол template, и allowlist сервера.
Имена по умолчанию работают вместе как единый комплект.

## Зачем Tasks и Reports?

Task определяет, что разрешено и требуется. Report фиксирует, что действительно
сделано и проверено. Разделение не позволяет принять план за доказательство.
