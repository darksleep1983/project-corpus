# Как это работает — без технической каши

У Project Corpus две части.

## 1. Corpus

Corpus — это папка с небольшим набором Markdown-файлов.

- `AGENTS.md` хранит правила работы;
- `PROJECT_ROADMAP_CURRENT.md` описывает активный проект и следующий шаг;
- handoff-файлы сохраняют контекст между чатами;
- `Tasks/` хранит точные задания;
- `Report/` хранит доказательства выполненной работы.

Это обычные текстовые файлы. Их можно открыть и прочитать без специальной программы.

## 2. MCP-сервер

MCP-сервер — это контролируемая дверь между AI-клиентом и Corpus.

Он не выдаёт AI полный доступ к компьютеру. Сервер настраивается на одну точную папку Corpus и сам ограничивает, какие файлы разрешено менять.

При обновлении сервер проверяет текущий SHA-256, создаёт резервную копию, атомарно заменяет файл, перечитывает результат и возвращает квитанцию операции.

## Зачем семь current-файлов

Они разделяют разные виды информации. Благодаря этому новый чат быстро восстанавливает текущее состояние и не принимает старую задачу или отчёт за актуальную истину.

## Что происходит в новом чате

```text
проверка health
→ чтение AGENTS.md
→ чтение current-файлов
→ определение активного проекта
→ загрузка только нужных Tasks и Reports
→ продолжение с точного следующего шага
```

## Что происходит на чистом листе

Corpus находится в состоянии `NO_ACTIVE_PROJECT`. Вы описываете новый проект обычными словами, после чего current-файлы заполняются под него.
