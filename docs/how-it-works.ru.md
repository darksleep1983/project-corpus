# Как работает Project Corpus

[English version](how-it-works.md)

Project Corpus хранит рабочую идентичность и непрерывность проекта в файлах,
которыми владеет сам проект. AI-клиенты и сессии могут меняться, а эти записи
остаются с проектом.

## Записи проекта V2

- `AGENTS.md` задаёт локальный workflow и правила полномочий проекта.
- `.project-corpus/state/PROJECT.md` хранит устойчивую идентичность,
  назначение и границы.
- `.project-corpus/state/STATUS.md` фиксирует проверенное текущее состояние,
  блокеры, ссылки на доказательства и точное следующее действие.
- `.project-corpus/tasks/` содержит ограниченные рабочие задания.
- `.project-corpus/reports/` фиксирует выполненную работу и доказательства.

В новой сессии следуйте `AGENTS.md`, прочитайте каноническую идентичность и
текущее состояние, загрузите только активную Task и относящиеся к ней
доказательства. Изменяемые факты сверяйте с живым проектом. Task описывает
разрешённую работу, Report — наблюдаемые результаты. Ни один из них не заменяет
каноническое состояние.

## Один протокол, несколько способов доступа

```text
локальная папка проекта ─┐
ручная загрузка файлов ──┼──> одни и те же Markdown-записи проекта
локальный stdio MCP ─────┘
```

Для ручной работы с Markdown Runtime устанавливать не нужно. Необязательный
локальный Runtime добавляет validation и controlled-операции для клиентов,
которым они нужны. MCP — один из способов доступа, но не источник полномочий.

## Совместимость с V1

В существующих проектах V1 сохраняются исходные семь файлов и инструкции
режимов доступа. Эти имена принадлежат V1; новые проекты следует начинать с
[минимального шаблона V2](https://github.com/darksleep1983/project-corpus/tree/main/templates/v2/minimal)
и [Quick Start](quickstart.md).
Необязательный Runtime может read-only спланировать миграцию и создать отдельное
назначение V2, не переписывая файлы V1. См. инструкции для [прямой папки](access/direct-folder.ru.md),
[ручной сессии](access/manual.ru.md), [своего MCP](access/own-mcp.ru.md) и
[миграции](migration/v1-read-only-planner.md).
