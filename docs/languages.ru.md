# Языки и паритет

[English](languages.md)

У Project Corpus два равноправных пользовательских языка: английский и русский.

- Исходные шаблоны V1 в `template/en` и `template/ru` содержат одинаковые семь
  authority-файлов и одинаковую структуру `Tasks/` и `Report/`.
- Новые проекты используют минимальный шаблон V2; см. [Quick Start](quickstart.md).
- README, инструкции режимов доступа и клиентов, project instruction, FAQ,
  security, contribution guidance, code of conduct, changelog и publishing
  checklist имеют английскую и русскую версию.
- Имена файлов протокола, константы режимов доступа и статусов, а также поля
  Task/Report остаются на английском, чтобы разные клиенты использовали один
  интерфейс.
- При изменении поведения обновляйте обе языковые версии вместе.
- Автоматические тесты проверяют паритет файлов и инвариантов, но не заменяют
  человеческую проверку перевода.

Для существующего проекта V1 скопируйте шаблон нужного языка. Для V2 следуйте
Quick Start. Markdown Protocol не требует установщика; Python нужен только
необязательному локальному Runtime.
