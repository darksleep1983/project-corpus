# GitHub Discussions plan

**Status: proposal only.** Discussions are currently disabled and require an
owner-side GitHub setting change.

| Category | Purpose | Keep out |
| --- | --- | --- |
| Announcements | Maintainer updates, releases, and roadmap notices | Support questions and feature requests |
| Q&A | Usage questions that are not reproducible defects | Secrets, vulnerability reports, and private Corpus content |
| Ideas | Early product and documentation proposals | Accepted bug reports or architecture decisions disguised as polls |
| Show and tell | Non-sensitive examples of how people use the Protocol | Personal project data or testimonials presented as verified metrics |
| Protocol | Interpretation and evolution questions about the Markdown contract | Runtime-specific support issues |
| Runtime / MCP | Controlled CLI, local stdio MCP, and integration questions | Third-party server security reports |

Pin a short welcome post that links to `SECURITY.md`, the FAQ, and the issue
forms. Public Discussions are not a vulnerability-reporting channel.
