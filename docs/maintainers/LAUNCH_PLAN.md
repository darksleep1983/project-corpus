# Social launch plan

**Status: draft only. Do not publish these plans without owner approval.**

| Channel | Angle and format | Include | Do not claim | Likely question |
| --- | --- | --- | --- | --- |
| Hacker News | Short technical “Show HN” post about durable Markdown state across clean AI sessions | README, Quick Start, repository link | Universal safety, production adoption, or benchmark results | Why not a database? |
| Reddit | Problem-first post in relevant AI/developer communities; ask for workflow feedback | Social preview and a minimal example | That it replaces every memory system | How is this different from a memory bank? |
| X | One concise before/after visual and a link | Social preview and current docs site | Launch metrics or vendor endorsement | Does it require MCP? |
| LinkedIn | Practitioner-oriented continuity and auditability explanation | Diagram, GitHub link, optional demo clip | Compliance certification or enterprise readiness | What guarantees exist? |
| MCP communities | State clearly that MCP is optional and local stdio-only | MCP doc and current PyPI install path | Remote MCP support or any unverified registry status | Can I install it from a registry? |
| AI-agent communities | Share a reproducible manual Quick Start and ask for integration feedback | Example project and loading prompt | Seamless support in every client | Which clients work? |

Before any post, verify links, social preview, public documentation availability,
release state, and that no private paths or unpublished security evidence are
included. Never manufacture testimonials, traction, or metrics.
