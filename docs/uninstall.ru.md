# Перенос или удаление Corpus

[English](uninstall.md)

Удалять приложение, службу, virtual environment или runtime не нужно: их нет.

## Перенос

1. Остановите активную работу и сделайте полный backup.
2. Перенесите всю папку Corpus вместе с `Tasks/` и `Report/`.
3. Обновите точное расположение в `CORPUS_ACCESS_CURRENT.md`.
4. Обновите локальную настройку клиента или своего MCP.
5. Начните новую сессию и выполните полную проверку загрузки.

## Удаление

Corpus содержит состояние проекта. Сначала сделайте backup, а затем удаляйте всю
папку Corpus только при осознанном решении удалить это состояние.

В ручном режиме также удалите старые загруженные копии из AI-проекта, если не
хотите хранить их там. В режиме своего MCP удалите конфигурацию сервера отдельно
по документации сервера и клиента.
