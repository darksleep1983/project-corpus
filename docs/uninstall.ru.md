# Удаление или перенос Project Corpus

Project Corpus не устанавливает системную службу. Перед изменением файлов
остановите запущенный HTTP-сервер через Ctrl+C.

## Сохранить память проекта

Безопасный вариант по умолчанию — сохранить данные проекта. Удалите из папки
репозитория только:

- .venv/
- .project-corpus.local.json

Ваши Corpus и папка mcp-state останутся в ProjectHome, который вы выбрали при
установке. Позже можно установить другую копию репозитория и направить её на тот
же ProjectHome только после проверки версии и политики резервных копий.

## Удалить всё

Corpus содержит состояние проекта, Tasks и Reports. Сначала сделайте backup или
export. Затем удалите весь ProjectHome, выбранный при установке. Это осознанное
разрушительное действие; установщик его не выполняет.

Если вы подключали сервер к AI-клиенту, удалите конфигурацию в самом клиенте.
Нужное место конфигурации указано в инструкции для соответствующего клиента.
