# Перенос или удаление Corpus

[English](uninstall.md)

Для Markdown Protocol не требуется приложение или служба. Необязательный
Runtime устанавливается как локальный Python-пакет; его удаление не удаляет
состояние проекта.

## Перенос

Для V2 перенесите проект вместе с `AGENTS.md` и каталогом `.project-corpus/`
либо следуйте правилам хранения самого проекта. Owner trust grant Runtime
привязан к физическому корню проекта, поэтому после переноса проверьте и заново
настройте полномочия по [инструкции CLI Runtime](runtime/cli.md), прежде чем
использовать controlled-операции.

Для существующего Corpus V1 перенесите всю его папку вместе с `Tasks/` и
`Report/`, затем обновите точное расположение в `CORPUS_ACCESS_CURRENT.md` и
конфигурациях клиента или стороннего MCP.

## Удаление состояния проекта

Сначала сделайте backup. Удаляйте каталог V2 `.project-corpus/` только если
действительно хотите удалить это состояние. Проверьте `AGENTS.md` и удалите
только инструкции Corpus, сохранив остальные правила проекта. Для V1 удаляйте
всю папку Corpus только если хотите удалить это состояние.

В ручном режиме удалите также загруженные копии из AI-проекта, если больше не
хотите их там хранить. Конфигурацию стороннего MCP удалите отдельно по
документации сервера и клиента.

## Удаление необязательного Runtime

Если пакет был установлен через pip, удалите его в том же Python-окружении:

```sh
python -m pip uninstall project-corpus
```

Проверьте и удалите внешний owner trust и Runtime state отдельно, согласно
выбранной вами конфигурации. Удаление пакета не удаляет Corpus проекта.
